**Exams restrict what you may reference, and the citations must obey that restriction.** SPCE 5065 exams open with an allowed-resources line and a signed honor statement ("I completed this assignment using only authorized references"). The midterm allowed: "any course notes, the textbooks by Tribble and/or Pisacane, any material on the Canvas page, and a calculator." Citing outside sources (NASA/NOAA/SpaceNews web pages, etc.) contradicts the signed statement, even when the fact is correct.

On Exam 1 the first-pass submission leaked three unauthorized web sources (NASA HRP, NOAA/NASA solar-cycle panel, SpaceNews/NASA ODPO). Jordan caught it and asked whether only allowed sources were cited. Every fact was recoverable from allowed sources:
- Human-factors facts (deconditioning, group dynamics, selection/training) -> Lesson 3 course notes (Canvas).
- Solar-cycle-25-vs-forecast -> Lesson 2 solar-cycle progression chart (course notes).
- Starlink 1100 km to 550 km altitudes -> stated in the exam problem itself, so no citation needed.
- Debris/radiation/charging physics -> Tribble.

**Why:** Direct user check after Exam 1. Unauthorized citations are an honor-code mismatch, not just a formatting nit.

**How to apply:** (1) Before drafting an exam submission, read the allowed-resources line and treat it as a hard whitelist. (2) Prefer Tribble/Pisacane and course notes/lessons (Canvas) for every claim; use facts stated in the problem statement directly. (3) Before finalizing, grep the submission for `http` and for any author/outlet not on the whitelist, and confirm zero. This is exam-specific; homeworks may cite external sources normally (see [[feedback_references]] for the AIAA numbering/inline-cite rules that still apply). Related: [[project_exam1_anchor]].
