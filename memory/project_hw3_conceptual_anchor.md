HW3 (`wk03/hw/Clayton_spce_5065_hw3_submission.md`) is the first **fully conceptual** SPCE 5065 homework produced through the prompt pipeline (bioastronautics, human factors, no orbital mechanics). It self-graded 96/100 (pipeline grader, not yet professor-graded). Use it as the in-course pattern anchor for the conceptual-heavy weeks, complementing HW1 which is the math-voice anchor.

What HW3 establishes for future conceptual assignments:
- **Current-events / presentation questions** (Q1): pull the actual presentations from the lecture transcript (`wk03/course_material/Lesson 3 Video Transcript.vtt`) and summarize what was really said, then add one specific "learned" and one question that targets a real weak point. Graded against the source, so do not answer from general knowledge.
- **NASA Bioastronautics / Human Research Roadmap tables** (Q5): the real Mars Red/Yellow/Green ratings live in the assignment PDF (the .md export strips the colors), so read the PDF. For a harder destination (Ceres), state 2-3 escalation levers once (longer duration, more radiation, near-zero surface gravity that removes reloading) and apply them uniformly across all rows.
- **SHELL model** (Q6, Q9): Software (procedures/docs), Hardware, Environment, central Liveware (human), Liveware-Liveware. Reuse one SHELL diagram across both problems. Apollo 13 for the single case (latent doc failure + recovered crew-ground seam); Challenger vs Columbia for the comparison (normalization of deviance at the L-L interface).
- **Weighted trade studies** (Q8): objectives, weighted criteria summing to 1, 1-5 scores, dot-product totals, name the near-miss for credibility. A small matplotlib bar chart of the weighted scores lands well.
- **Figures still help conceptual work**: HW1's grader wrote "Nice graph!", so conceptual submissions still benefit from 2-3 matplotlib figures (a Celentano-style volume curve, a SHELL diagram, a trade-study bar chart). Light theme for the submission; dark theme (`#0D1117` bg) for the walkthrough.
